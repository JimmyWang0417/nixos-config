# Orion-Laptop 适配清单

对照的是正在运行的 Manjaro 和仓库里已经写上的文件。没写进 Nix 文件的功能不记成已迁移。27 项不能原样入库的内容在「未覆盖」和「敏感数据」里，没有密钥原文。

## 主机与多设备

- 主机名 `Orion-Laptop`：`hosts/orion/default.nix` 的 `networking.hostName`。flake 属性名是 `orion`，`flake.nix` 的 `nixosConfigurations.orion` 把 `hostName` 传进 specialArgs。
- 主机事实只放在 `hosts/orion/default.nix`：文件系统、initrd、内核、微码、固件、打开哪些 `orion.*`。
- 共享模块在 `modules/`，开关默认关闭，由主机打开。再加一台机器：复制 `hosts/example.nix` 为 `hosts/<名字>/default.nix`，在 `flake.nix` 加一条属性，只改主机名、硬件、要启用的配置。
- 用户家目录由主机导入 `home/jimmy.nix`，不写死在某个无关模块里。
- 渠道：`nixpkgs` 为 `github:NixOS/nixpkgs/nixos-26.05`，锁定 `f1e5c356f35d07e7b71a6b5e6c9338e0b029e0c0`。`home-manager` 为 `release-26.05`。`nixos-26.11` 还没有分支，也不跟 `nixos-unstable`。`system.stateVersion` 和 `home.stateVersion` 都是 `26.05`。

## 硬件与启动

- CPU Intel i9-12900H：`hosts/orion/default.nix` 导入 `nixos-hardware` 的 `common-cpu-intel`，并设置 `hardware.cpu.intel.updateMicrocode`、`boot.kernelModules = [ "kvm-intel" ]`、`boot.kernelPackages = linuxPackages_6_12`。
- 核显 Iris Xe `[8086:46a6]`：同一文件的 `hardware.graphics.extraPackages` 使用 `intel-media-driver`（含 32 位）。PCI `PCI:0:2:0` 交给 `orion.nvidia.intelBusId`。
- 独显 RTX 3060 Mobile `[10de:2520]`：`modules/nvidia.nix` 的 `hardware.nvidia.prime.offload`，`open = true`，`modesetting.enable`，`powerManagement.enable`，`finegrained = true`。独显 PCI `PCI:1:0:0` 在主机文件。
- 根分区 btrfs UUID `fd32207f-8a11-48d7-9d04-9316cdb8c265`：`hosts/orion/default.nix` 挂载 `/` 子卷 `@`、`/home` 子卷 `@home`、`/var/cache` 子卷 `@cache`、`/var/log` 子卷 `@log`，选项含 `compress=zstd:1`。
- EFI `0AF1-1155` 挂到 `/boot/efi`。nvme0 上的 Windows NTFS 和 nvme1 上未挂载的数据分区没有写成 `fileSystems`。
- 引导：`modules/boot.nix` 启用 GRUB EFI，`useOSProber`，EFI 挂载点 `/boot/efi`，`canTouchEfiVariables` 默认 false。本仓库不执行 `nixos-rebuild`。
- 内核参数：主机文件只保留 `mem_sleep_default=deep`。modeset 和 fbdev 走 `hardware.nvidia.modesetting`，不手写重复的 `quiet`。
- 交换和休眠：`swapDevices = [ ]`。现场没有 swapfile，命令行里的 `resume=` 没有迁进来。
- 默认会话是 Plasma X11。`hosts/orion/default.nix` 把 `orion.desktop.defaultSession` 设为 `plasmax11`。`modules/desktop.nix` 把它写到 `services.displayManager.defaultSession`。Wayland 会话名 `plasma` 仍随 Plasma 6 安装，但不是默认项。
- 触摸板点击和自然滚动、鼠标 flat 加速度：`modules/desktop.nix` 的 `services.libinput`。
- Wi-Fi 和有线网卡不单独写驱动名，由 `hardware.enableRedistributableFirmware` 和 NetworkManager 使用内核自带的 iwlwifi、r8169。

## 中文环境

- 输入法是 fcitx5 拼音，不是 Rime。`modules/chinese.nix` 设置 `i18n.inputMethod.type = "fcitx5"`，`waylandFrontend = true`，附加组件为 `qt6Packages.fcitx5-chinese-addons`、`fcitx5-gtk`、`qt6Packages.fcitx5-configtool`、`qt6Packages.fcitx5-qt`。
- 现场读过的配置：`/etc/environment`、`~/.config/fcitx5/profile`、`~/.config/fcitx5/conf/pinyin.conf`。后两份在 `home/fcitx5/`，由 `home/jimmy.nix` 复制到新家目录。组名是「默认」，包含 `keyboard-cn` 和 `pinyin`。云拼音开关在 `pinyin.conf`。用户词库不在仓库里。
- 字体：`modules/chinese.nix` 安装 Noto、Noto CJK、Noto Color Emoji、文泉驿微米黑、Source Sans、Liberation、DejaVu、Inconsolata、Terminus。`fonts.fontconfig.defaultFonts` 只有一条回退链，无衬线从 Noto Sans CJK SC 开始。
- 时区 `Asia/Shanghai`、locale `zh_CN.UTF-8`、X11 布局 `cn`、RTC 不使用本地时间、`services.timesyncd.enable`：`modules/locale.nix`。主机只打开 `orion.locale.enable`。
- 国内镜像：`modules/nix-settings.nix` 的 `orion.nix.chinaMirrors.substituters`，默认是 `https://mirrors.ustc.edu.cn/nix-channels/store` 和 `https://cache.nixos.org/`。主机打开了这个开关。

## 优化

来自 `inventory/optimizations.md`，功能仍在：

- mhwd 把 `drm`、`ttm` 也拉黑了。`modules/nvidia.nix` 只走 NixOS 的 NVIDIA 模块，核显还在。
- `nvidia-prime` 和 mhwd 各配一次混合显卡。现在只有 `hardware.nvidia.prime.offload`。
- 休眠参数指向不存在的 swap。`hosts/orion/default.nix` 不写 resume，保留 `mem_sleep_default=deep`。
- `/etc/environment` 里输入法变量重复，并且 GLFW 被设成 ibus。只保留 fcitx5 一条路径。
- fontconfig 多层优先级收成 `modules/chinese.nix` 的一条 `defaultFonts`。
- SDDM 的 breath 和 breeze 冲突。采用后加载的 breeze，`modules/desktop.nix`。
- neofetch 已从 nixpkgs 删除。现场的 fastfetch 留在 `modules/packages.nix`。
- 这台是 Intel，不装 amd-ucode。VA-API 用 `intel-media-driver`，不用旧的 i965。acpid 不启用，电源交给 logind。NTP 用 `modules/locale.nix` 的 timesyncd，不并行 ntpd。
- pamac、mhwd、Manjaro 主题不进配置。软件改由本仓库声明，引导用 GRUB。
- `networkmanager-vpnc` 已被上游删除。不改成 libreswan。OpenVPN、L2TP、OpenConnect 仍在 `modules/networking.nix`。
- 现场防火墙是关的。NixOS 默认防火墙打开，并放行 KDE Connect。
- 自动登录只在主机文件打开，共享模块没有 `mkForce`。
